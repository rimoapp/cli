# Contributing

[English](CONTRIBUTING.en.md) | [日本語](CONTRIBUTING.md)

Thanks for your interest in the Rimo CLI (`rimo`)! This repository is the official home for
its documentation and released binaries, and we welcome your feedback.

## Feedback

- **Bug reports** — open a GitHub issue with your `rimo version`, your OS/architecture,
  steps to reproduce, and what you expected to happen.
- **Feature requests** — open an issue describing the use case and the problem you're
  trying to solve.
- **Documentation** — if something under [`docs/`](docs/) is wrong or unclear, open an issue.

## Security

Please **do not** open public issues for security vulnerabilities. Follow the
[Security Policy](SECURITY.md) and email **security@rimo.app** instead.

## Before filing an issue

- Make sure you're on the latest release (`rimo upgrade`) — only the latest version is
  supported.
- Search existing issues to avoid duplicates.
- Never include API tokens or other secrets — redact them first.
